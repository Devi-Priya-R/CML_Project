# 💊 Drug Recommendation System

## 📌 Project Overview
The Drug Recommendation System is a Python-based machine learning project that predicts a possible disease based on user-selected symptoms and provides related information, including disease descriptions, precautions, medications, diet recommendations, and workouts.

The project explores how machine learning can be used to process symptom data and generate informative predictions through an application interface.

## ✨ Features
- Symptom-based disease prediction
- Disease descriptions and related information
- Precautions associated with predicted diseases
- Medication information
- Diet and workout recommendations
- Interactive application interface

## 🛠️ Technologies Used
- **Python** — application logic and data processing
- **Machine Learning** — disease prediction
- **Scikit-learn** — machine learning model implementation
- **Pandas** — dataset handling
- **Flask** — web application framework, if used in the current version
- **CSV datasets** — symptom and disease-related information

## 📂 Project Files
- `app.py` — application interface and workflow
- `train.py` — model training and prediction-related functions
- `test.py` — prediction testing
- `Training.csv` — training dataset
- `Symptom_severity.csv` — symptom severity information
- `description.csv` — disease descriptions
- `precautions_df.csv` — precaution information
- `medications.csv` — medication information
- `diets.csv` — diet recommendations
- `workout_df.csv` — workout recommendations


## 🚀 Learning Outcomes
Through this project, I explored Python programming, machine learning workflows, dataset processing, model integration, and the development of an application that connects model predictions with user-facing information.

## ⚠️ Disclaimer
This project is intended for educational purposes only. Its predictions and recommendations are not medical advice and should not be used to diagnose diseases or choose medications. Always consult a qualified healthcare professional for medical decisions.
